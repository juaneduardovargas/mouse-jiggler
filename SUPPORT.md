# Support

[Leer en español](docs/es/SUPPORT.md)

Mouse Jiggler is maintained as a personal open-source project. Community support is provided on a best-effort basis.

## Where to ask

- Use the **Bug report** issue form for reproducible defects.
- Use the **Feature request** issue form for improvement proposals.
- Use a regular issue for documentation questions that do not fit either form.
- Use private vulnerability reporting for security-sensitive matters.

## Include this information

- macOS version and Mac architecture (`arm64` or `x86_64`).
- How the app was installed or built.
- Whether Accessibility permission is enabled.
- Exact steps to reproduce the problem.
- Relevant screenshots or terminal output with personal data removed.

## Scope

The project can help with source builds, app behavior, translations, permissions, and packaging scripts. Apple Developer enrollment, certificate issuance, account recovery, and organization-managed macOS policies are outside the project's control.
