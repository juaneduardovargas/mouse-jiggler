# Soporte

[Read in English](../../SUPPORT.md)

Mouse Jiggler se mantiene como un proyecto personal de código abierto. El soporte comunitario se ofrece según la disponibilidad del mantenedor.

## Dónde preguntar

- Usa el formulario **Bug report** para errores reproducibles.
- Usa el formulario **Feature request** para propuestas de mejora.
- Usa un issue normal para preguntas de documentación que no encajen en esos formularios.
- Usa el reporte privado de vulnerabilidades para asuntos sensibles de seguridad.

## Incluye esta información

- Versión de macOS y arquitectura del Mac (`arm64` o `x86_64`).
- Forma en que instalaste o compilaste la app.
- Si el permiso de Accesibilidad está activado.
- Pasos exactos para reproducir el problema.
- Capturas o salida de terminal relevantes, sin información personal.

## Alcance

El proyecto puede ayudar con builds desde el código fuente, comportamiento de la app, traducciones, permisos y scripts de empaquetado. La inscripción en Apple Developer, emisión de certificados, recuperación de cuentas y políticas administradas de macOS están fuera del control del proyecto.
